==========================================
Google OAuth 설정 방법 (최초 1회만 필요)
==========================================

1. https://console.cloud.google.com 접속 후 Google 계정 로그인

2. 상단 프로젝트 선택 → "새 프로젝트" 클릭
   - 프로젝트 이름: 정산자동화 (임의로 입력)
   - "만들기" 클릭

3. 좌측 메뉴 → "API 및 서비스" → "라이브러리"
   - "Google Sheets API" 검색 → 클릭 → "사용 설정"

4. 좌측 메뉴 → "API 및 서비스" → "OAuth 동의 화면"
   - 사용자 유형: "외부" 선택 → "만들기"
   - 앱 이름, 이메일 입력 후 저장

5. 좌측 메뉴 → "API 및 서비스" → "사용자 인증 정보"
   - "+ 사용자 인증 정보 만들기" → "OAuth 클라이언트 ID"
   - 애플리케이션 유형: "데스크톱 앱" 선택
   - 이름 입력 후 "만들기"
   - "JSON 다운로드" 클릭

6. 다운로드된 파일 이름을 credentials.json 으로 변경
   → 정산자동화.exe 와 같은 폴더에 넣기

7. 프로그램 실행 후 "Google 로그인" 버튼 클릭
   → 브라우저가 열리면 Google 계정으로 로그인
   → 최초 1회만 하면 이후 자동 로그인
